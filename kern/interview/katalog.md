# Question catalogue (core)

Setup asks at most the three questions of skill `einrichten` (where and school type · classes and subjects · anything special). Everything below is asked **only when a task needs the answer**, one or two questions at a time, in the teacher's language – never as an interview up front. The IDs are stable so that answers always land in the same place (`ableitung.md`). Never ask for pupil data; an unknown answer stays `[ ]`. At a transition (skill `uebergang`) ask only the IDs marked ↻ whose answers may have changed.

| ID | Question (German default) | Needed for |
|---|---|---|
| R1–R3 | Land, Bundesland/Region, Schulform | setup (question 1) |
| R4 ↻ | In Ausbildung (wie heißt das bei dir?), ausgebildet oder Quer-/Seiteneinstieg? | setup (question 3) |
| R5 ↻ | Falls in Ausbildung: Wann endet sie? | transition reminders |
| R6 | Anrede und Sprache | taken from how they write; ask only if unclear |
| U1 ↻ | Welche Klassen/Kurse und Fächer? | setup (question 2) |
| U2 ↻ | Wie viele Stunden pro Woche, an welchen Tagen? | year plan, counting the lessons of a unit |
| U3 | Wie lang ist eine Stunde, wie ist das Stundenraster? | clock times in plans (default 45 minutes, named as assumption) |
| U4 ↻ | Welche Lehrwerke nutzt du? | references to book pages |
| U5 ↻ | Schuleigene Termine (Projektwoche, Prüfungszeiträume)? | year plan, unit dates |
| P1 ↻ | Welche Dokumente musst du abgeben – für wen, bis wann? | when they mention a duty |
| P2 ↻ | Gibt es dafür eine verbindliche Vorgabe (von wem)? | setup (question 3); requirements go before wishes |
| P3 ↻ | Stehen Besuche, Prüfungen oder Abgaben mit Datum an? | reminders (`kern/regeln.md` §3) |
| P6 | Hast du ein Beispiel deines Formats? | only when they want their own format reproduced |
| V1–V4 | Per feature of their example: Vorgabe (von wem?), Vorliebe oder nur in diesem Beispiel? Fehlt etwas aus der Vorgabe? Gibt es eine Variante für Besuche oder Prüfungen? Passt die Vorschau? | inside skill `vorlage-ableiten` |
