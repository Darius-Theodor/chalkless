# Rückmeldungen (nur anhängen)

> Jede Änderung, die du dir wünschst, bekommt eine Zeile: `- JJJJ-MM-TT · Bereich · Typ · Art: Wunsch · Regel: keine|gefragt|bestätigt|abgelehnt`. Frühere Einträge werden nie geändert.
> Wünschst du dir dasselbe ein zweites Mal, fragt der Agent einmal, ob er es künftig immer so machen soll.
